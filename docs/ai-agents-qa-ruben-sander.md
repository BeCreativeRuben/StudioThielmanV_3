# AI-agents — Q&A voor Ruben & Sander

Interne afstemming vóór we het teaser-aanbod op `/ai-agents` verder uitwerken of prijzen publiceren. Teaser live = geen prijzen, geen harde beloftes; CTA = Book-a-Call of doorverwijzing naar `/workshops`.

## Positionering (huidige publieke copy)

- **Wat:** lokale / on-prem (of volledig binnen klantomgeving) AI-agents voor **interne** bedrijfsprocessen — niet publieke marketing-chatbots.
- **Voor wie:** KMO’s die data en processen privé willen houden.
- **Status:** aanbod in uitwerking (o.a. met technische partner). Publieke pagina is teaser + gesprek.
- **Eerste stap vandaag:** hands-on AI-workshop (`/workshops` → `/ai-talks` formats).

## Open vragen (in te vullen samen)

### Product & scope
1. Wat is de **MVP** van een “lokale AI-agent” die we in 2026 kunnen leveren? (welke taken: tickettriage, offerte-draft, kennisbank-Q&A, planning, …)
2. Wat is **expliciet out of scope** in v1? (CRM-vervanging, customer-facing bot, training op gevoelige HR-data, …)
3. Draait de agent **volledig offline**, of mag er een gecontroleerde cloud-LLM achter zitten zolang data on-prem blijft?
4. Welke **runtimes** willen we steunen (Mac mini / Windows server / Docker / bestaande VPS van de klant)?
5. Hoe koppelen we aan bestaande tools (mail, Notion/SharePoint, booking, ERP)? MCP / API / manuele export?

### Verantwoordelijkheid & partnership
6. Wie is **product owner** (Ruben) vs **tech lead** (Sander) vs externe partner?
7. Welke IP / branding: Studio Thielman product, white-label, of joint venture?
8. Wie doet **support** na go-live (SLA, response time, updates van models)?

### Privacy, compliance, veiligheid
9. Welke **data** mag de agent zien? Hoe loggen / auditten we prompts & outputs?
10. Wat beloven we rond **GDPR** (verwerkersovereenkomst, data residency BE/EU, retention)?
11. Mogen we klantcases publiek noemen? Zo ja, vanaf wanneer?

### Commercieel (nog niet op de site)

13. Wat is een realistische **pilotduur** en succescriterium voor een eerste klant?
